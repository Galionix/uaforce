# UA Force — бесплатная демоверсия и кооператив

Дата: 2026-09-09. Основание: документ владельца, переданный в текущей задаче Codex. Это адаптация к проверенному коду, а не новая трактовка дизайна.

## Требования владельца

- «Не тормозить релиз ради “идеальной” инфраструктуры».
- «Single-player должен продолжать работать независимо».
- «Не позиционировать публично как “клон Broforce”».
- «Client 2 input → Host → simulation/state → Client 2».
- «Не блокировать публичный билд из-за multiplayer».
- «используй бд новледж чтобы прикрутить оплаты и донаты».
- Бесплатный запуск без регистрации; поддержка разработки добровольная.
- Два игрока, код/ссылка комнаты, host authority, WebRTC. Signaling/STUN обязательны для схемы; TURN может понадобиться некоторым сетям.
- Поэтапные проверки: соединение → два персонажа → оружие/урон/умения → AI/разрушение/pickups → разрыв связи.
- История Git, авторство, дизайн-документы и сохранённые исходники материалов; короткие ролики и публичный первоисточник. Не раскрывать все будущие механики.

## Evidence — проверено в проекте

Рабочая игра — TypeScript + Canvas2D, Vite 8.2.2. PlayCanvas 2.22.1 используется только старым просмотрщиком материалов, не публичной игрой. Симуляция `World`, ввод `Input`, отрисовка `View` уже раздельны, но до этого этапа мир имел одного игрока.

Хостинг называется **Cloudflare Pages Free**. Игра уже опубликована: https://uaforce.thedimas.com, резерв https://uaforce.pages.dev. Используется Direct Upload, HTTPS/CDN, регистрация игрокам не нужна. Перенос на itch.io не требуется.

Предыдущий проверенный релиз: 97 файлов, 61.89 MiB; крупнейший PCM-банк 7.40 MiB. Текущие ограничения Free: 20 000 файлов и 25 MiB на файл; Dashboard upload имеет отдельный меньший лимит количества файлов, наш артефакт ниже него. [Cloudflare limits](https://developers.cloudflare.com/pages/platform/limits/), проверено 2026-09-09. Статика не заменяет signaling или TURN.

Репозиторий Galionix/uaforce уже публичный, но каталог новой игры был незакоммичен. Коммит `bb1632c` сохраняет исходный рабочий прототип перед сетью. Приватные переписки, финансовые сведения и будущие концепции не входят в публичный пакет.

## Решение и порядок

| Приоритет | Этап | Доказательство завершения |
|---|---|---|
| P0 | Сохранить рабочий single-player | Отдельный коммит, прежние тесты и публичный URL |
| P0 | Публичная упаковка | UA Force, автор, короткое описание, поделиться, без paywall |
| P0 | Поддержка | Проверенная внешняя форма действующего получателя; никаких ключей/карт в игре |
| P1 | Два игрока в одном World | Независимые input/HP/магазины/умения/призывы, мир шагает один раз |
| P1 | Комнаты | PeerJS 1.5.5; код, ссылка, два клиента, timeout/leave |
| P1 | Host authority | Guest присылает только валидированные inputs/меню-команды; host отправляет snapshots/events |
| P1 | Проверки | Тесты SP и co-op; два браузерных клиента без звука |
| P2 | Первые внешние тесты | Другие компьютеры/сети, macOS и Windows, реальный геймпад |
| P2 | Следующий netcode | Измеренные задержки/NAT ошибки → решение по TURN и prediction |

## Минимальная сетевая схема

Библиотека PeerJS загружается отдельным чанком только при входе в online. Бесплатный PeerServer Cloud — signaling; стандартная конфигурация PeerJS — STUN; игровой трафик WebRTC между двумя браузерами. Собственный постоянно работающий сервер, аккаунты, matchmaking, host migration и progression backend не добавляются.

[PeerServer Cloud](https://peerjs.com/server/cloud), [PeerJS FAQ](https://peerjs.com/client/faq), [PeerJS API](https://peerjs.com/client/api/peer), проверены 2026-09-09. Общий бесплатный signaling не имеет нашего SLA. Первоначальные TURN defaults библиотеки оказались недоступны. После реального сообщения владельца о тайм-ауте подключён Cloudflare TURN, проверен принудительный relay; детали в ONLINE_VERIFICATION.md. Долю неудачных NAT-соединений определяют реальные тесты, а не выдуманный процент.

Симуляция host 60 Hz, снимки 20 Hz, guest inputs 30 Hz. Terrain передаётся накопительными изменениями от начального уровня. Динамические сущности и события — от host. Версия протокола/порядковые номера защищают от смешения версий и устаревших inputs. Пауза общая. Закрытие host завершает комнату; SP-запись сохраняется отдельно. Для первой тестовой версии кооператива возвращение после гибели не исчерпывает партию: каждый игрок возвращается на свой checkpoint. Это рекомендация реализации MVP, не исходная идея команды.

## Публичность и продвижение

Авторская подпись опирается на существующий публичный псевдоним Dimasss / Galionix; команда — UA Force. Предложения будущих персонажей/сюжета остаются внутренними.

Каждая короткая запись: механика → один понятный смешной момент → 6–15 секунд → ссылка https://uaforce.thedimas.com. Первая аудитория — друзья и команда, затем небольшие украинские сообщества. Публикационные тексты и кадры сохраняются отдельно; автоматическая рассылка/постинг не настроены.

Платная инфраструктура и окончательная монетизация не нужны для этого релиза. Добровольная поддержка не открывает героев и не влияет на баланс.


### Текущий relay и стоимость

Для резервного WebRTC-пути используется Cloudflare Realtime TURN. Первые 1 000 ГБ в месяц входят бесплатно, затем $0.05/ГБ; подключение с такими условиями одобрено владельцем 2026-09-09. Это отдельный сервис от Pages Free. [Официальный тариф](https://developers.cloudflare.com/realtime/sfu/pricing/). Серверный endpoint выдаёт только временные credentials; master token хранится в Secret binding. Эвристическое ограничение частоты запросов не является жёстким бюджетным лимитом. Собственный постоянно работающий игровой сервер не добавлен.
