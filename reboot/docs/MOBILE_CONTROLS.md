# UA Force — мобильный тест

10 сентября 2026. Опубликовано: https://uaforce.thedimas.com
Cloudflare Pages Production: `23ce9cb4-e504-49d0-a4de-e805d8e21fb4`.
Предыдущая версия для отката: `d4a6e300-400b-440f-8698-f76f3666d761`.

## Поведение

- Автоопределение по coarse pointer, touch points и мобильному user-agent; учтён iPad с desktop UA. В настройках можно принудительно включить/выключить сенсорное управление.
- Слева стик: движение и лестницы. Справа атака, прыжок ✕, взаимодействие □, спецприём и ульта. Оригинальные иконки героя, кольца перезарядки, патроны/заряды. Танк прыгает на ✕, выход на □.
- Разные указатели могут держать стик и кнопки одновременно. Отмена касания, потеря фокуса, меню и поворот очищают ввод. Короткие касания сохраняются до игрового опроса.
- Портретный режим во время игры вызывает паузу и подсказку поворота; есть выход в главное меню. Возврат горизонтально не возобновляет игру без действия игрока.
- Fullscreen только по нажатию, затем попытка landscape lock. Отказ API не мешает играть горизонтально во вкладке. Нет принудительного CSS-поворота сцены.
- Сохраняется поле 640×360 и масштабирование 16:9; safe-area отступы, компактное меню, HUD вне зон больших пальцев. Touch подаёт стандартные Actions, сохраняются keyboard/gamepad и текущая схема авторитетного host.
- /tiktok теперь предлагает мобильный тест; в отчёте об ошибке источник управления может быть touch.

## Проверки

- Полный набор 315/315 прошёл после добавления первых четырёх touch-тестов. Затем добавлены три fullscreen-теста и отдельно прошли все 7/7 touch/fullscreen-тестов. Полный набор после последних трёх тестов не повторялся.
- TypeScript, release build и проверка ZIP прошли: 109 файлов, 71.03 MiB. Без новых зависимостей и генераций.
- Локальная проверка в Codex in-app Browser: landscape 844×390 и 667×375, меню и кнопки без пересечений, прыжок/атака, пауза, portrait 390×844. Обычный desktop скрывает touch UI.
- Production проверен по фактическому Deployment в Cloudflare и новой игре на основном домене: старт SP, сенсорные кнопки, портретная пауза, «До меню». Console error пуст. Все игровые проверки silent=1.
- CDP touch-event injection здесь недоступен. Комбинации нескольких касаний проверены на уровне Input/TouchState, не физическими пальцами. Fullscreen/lock ошибки и порядок вызовов проверены mock-тестами.

## Следующий физический плейтест

На Android/Chrome и iPhone/Safari: открыть ссылку, повернуть горизонтально, нажать полный экран (если доступен); одновременно двигаться, стрелять и прыгать; проверить лестницу, бочку, танк, способности, паузу, сворачивание и возврат. Затем попробовать кооп с ПК из другой сети. Оценить производительность и удобство расположения кнопок. Встроенный браузер TikTok проверить отдельно; при ограничениях открыть ссылку во внешнем браузере. Эти проверки ещё не выполнены, гарантий мобильной совместимости нет.


## 11 сентября 2026 — читаемость на iPhone 12 mini

Источник: пользователь и друг сыграли в кооп на телефонах. Подтверждена модель друга — iPhone 12 mini; Safari предположительно, версия iOS неизвестна. Друг сообщил об увеличении страницы после двойного тапа, слишком маленьких элементах управления и сцене. Это первый описанный пользователем физический мобильный кооп-тест; прежний раздел «Следующий физический плейтест» относится к состоянию 10 сентября.

Изменения:
- Стик на горизонтальном viewport 812×375 увеличен с примерно 128 до 165 CSS px. Минимум 148 px; основные кнопки — минимум 54 px, атака крупнее. Safe-area сохранены.
- Мобильная сцена по умолчанию приближена до 135%. Настройка «Наближення сцени» — 100–150%, сохраняется после перезагрузки.
- При расхождении игроков по горизонтали или высоте камера отдаляется, чтобы оба оставались видны. Учитывается размер танка. Это только отображение: сетевое состояние, физика и ограничение расстояния между игроками не менялись.
- Камера выводит стартового героя из-под левого стика. Катсцены сохраняют полный кадр. Пиксельное изображение масштабируется без сглаживания.
- Игровые поверхности используют touch-action:none и отмену браузерных touch/gesture/double-click действий во время активного управления. Обычные меню и настройки не получили глобальный запрет масштабирования.

Проверки:
- 323/323 теста прошли; TypeScript и release build прошли. ZIP: 110 файлов, 71.28 MiB.
- Локально проверены компактные раскладки, кадр 812×375, изменение масштаба до 150%, сохранение после перезагрузки и возврат к 135%. Беззвучная отдельная сцена проверяет двух игроков рядом, по краям и на разной высоте; это проверка отображения, не новый физический сетевой тест.
- На production проверен запуск одиночной игры, сенсорное управление, стик 165 px, масштаб 135%, отсутствие горизонтального переполнения при 812×375. Загружены новые game-B-iHEquj.js и game-5LaMveNE.css. Все игровые проверки silent=1.
- Cloudflare Pages Production: e779d53d-3564-4456-8e02-077e8b1f92a7; основной URL https://uaforce.thedimas.com. Предыдущая версия для отката: be2a2502-d4b2-4838-aec2-537c1b428e6d.
- Прямой HTTP-запрос из Python получил 403; опубликованный билд проверен через авторизованный Codex in-app Browser и панель Cloudflare.

Ограничение: реального iPhone здесь нет. Предотвращение двойного тапа и одновременные касания после этой правки ещё нужно повторить в Safari на телефоне друга; браузерная проверка размеров не заменяет тест WebKit на iOS.
