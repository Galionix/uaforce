# Звуки загибелі: перевірка та заміна

2026-09-09. Власник просить різні згенеровані реакції загибелі для ворогів, вибухи, мультяшне чавкання/хлюпання та окремі фінали босів.

## Перевірений поточний стан

- `audio.ts`: `enemyDeath` грає спільний `pain1.wav` і `shevchenko-hit`. Це не Lyria.
- `world.ts`: подія `enemyDeath` не передає тип піхоти й причину смерті аудіосистемі; ці дані зараз використовуються лише для текстової репліки.
- Техніка та боси дають спільний `burst` / `explosion`. `bossDefeated` має оголошення перемоги, але не індивідуальний звук руйнування боса.
- Окремого банку мокрих бризок/чавкання немає. Фізика крові косметична; не додавати через неї шкоду.

## Спроба Lyria

Згенеровано три майстри: реакції піхоти, мокрі бризки, фінали босів. Усі збережені локально з хешами в `DEATH_SFX_GENERATION_STATUS.json`. Перший запит повернув технічну помилку; повтор створив файл. Повідомлення про квоту не було.

Окрема сесія Gemini отримала самі WAV перших двох файлів для аналізу: виявлено музичну підкладку, ритм і вокальні вставки; чистих ізольованих ефектів не знайдено. Це аналіз моделі, не людське прослуховування. Майстер босів експортований, ще не перевірений. Нові файли не підключені й не опубліковані. Опис генератора про «відсутність музики» не є доказом вмісту.

## Пакет для наступної генерації

- Сім типів піхоти (`rifle`, `assault`, `gunner`, `sniper`, `scout`, `shield`, `demolition`): щонайменше три короткі різні невербальні реакції для кожного; вибір без негайного повтору.
- Мокрі ефекти: окремі варіанти удару, хлюпання, гумового квакання й падіння шматочків. Падіння озвучувати при контакті з поверхнею, з обмеженням одночасних звуків.
- Вибухи: короткий, важкий, техніка та уламки; не дублювати один вибух усіма шарами загибелі.
- Герасімов: руйнування важкої броні. Суровікін: злам роторів і розсип дрібних детонацій. Хуйло: окремий потужний фінал. Зберегти український анаунсер.
- Передавати роль/причину загибелі через події host → guest; відстань, пауза й ліміт голосів мають діяти на нові звуки.
- Перш ніж міняти всю бібліотеку, перевірити пробні ефекти на придатність і походження. Без осциляторних підмін і нарізання музики під виглядом SFX.
