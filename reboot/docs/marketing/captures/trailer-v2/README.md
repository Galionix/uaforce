# UA Force — сила має характер

Другий оглядовий трейлер, 2026-09-09. 89 секунд, 1920×1080, 30 fps, H.264/AAC. Фінальний файл: `UA-Force-trailer-Kore-uk.mp4`; українські субтитри: `UA-Force-trailer-Kore-uk.srt`. Це матеріал для перегляду автором, ще не публікація в соцмережах.

## Звук

Жіночий український голос **Google Kore**. Стиль: впевнена, яскрава, грайлива подача. Кліпи 0–6 — `gemini-3.1-flash-tts-preview`; кліпи 7–9 — підтримувана Google модель `gemini-2.5-flash-preview-tts`, той самий Kore. Причина вибору другої TTS-моделі для останніх реплік: API поточного проєкту повідомив денний ліміт FreeTier для 3.1. Платіжні налаштування та акаунти не змінювалися. Точний текст, модель кожної репліки та таймінги збережені у `script.json` і `narration.json`.

Музика та SFX — чинний ігровий аудіограф (river-combat, бойові семпли), а не нові синтезаторні заглушки. Мелодію головного меню не використано. Під мовлення ігровий звук автоматично приглушується. Під час виробництва звук записувався лише через MediaStreamAudioDestinationNode і не був підключений до динаміків. Перевірка вимови через автоматичну транскрипцію збережена в `voice-transcript-check.json`; вона не замінює суб’єктивну оцінку озвучки автором.

## Кооп і постановочне керування

Це реальні два OnlineRoom/PeerJS/WebRTC-клієнти та авторитетна симуляція host; другий клієнт надсилає inputs і отримує snapshots. Сцена записана на одному комп’ютері з керуванням за сценарієм. Під час зйомки діє невразливість, лише у capture fixture. Це не запис гри двох людей через різні домашні мережі. Свідчення конкретного дубля: `coop-proof.json` (296 snapshots, 1080 inputs, переміщення P2, двоє у стані guest). Окремий тихий мережевий прогін також перевірив рух, постріли, урон, паузу та вихід.

## Відтворення

1. Dev server на 127.0.0.1:5178.
2. `python3 tools/capture-receiver.py --output docs/marketing/captures/trailer-v2/gameplay-source.webm`.
3. Відкрити `/tools/capture-trailer.html` у Codex Browser, дочекатися двох з’єднаних клієнтів, натиснути запис.
4. `python3 tools/build-trailer.py voice --env-file <private-env-file>` — кеш за хешем тексту, стилю, голосу та моделі.
5. `python3 tools/build-trailer.py mix` — нормалізація, speech ducking, MP4 та SRT. Не програє звук.
6. Перевірити MP4 через ffprobe/ffmpeg і контактний аркуш; зупинити receiver та закрити capture tab.

Вихідний WebM, усі WAV, сценарій та перевірки збережені поряд локально. Секрети/API-ключі в цій папці та репозиторії не зберігаються. Single-player і публічний білд не змінювалися.
