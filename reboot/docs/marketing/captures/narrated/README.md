# UA Force — український огляд геймплею

Запис 2026-09-09. `UA-Force-gameplay-uk.mp4`: 37 секунд, 1920×1080, 30 fps, H.264/AAC. Український жіночий коментар Gemini TTS, голос Kore; точні тексти, модель і таймінги — `narration.json`. Субтитри — `UA-Force-gameplay-uk.srt`.

Відео записане у Codex Browser через `tools/capture-narrated.html`: справжні World/View/Sound та наявні ігрові асети. Чотири постановочні фрагменти з керуванням за сценарієм; невразливість ввімкнена лише для зйомки. Це не запис зовнішнього плейтесту. Показані Шевченко, Леся Українка, Бандера, Привид Києва; монтажні переходи кожні 8 секунд, запрошення зіграти після 32-ї секунди.

Звуки зброї, спецприйомів, ульт і музика записані з ігрового аудіографа через MediaStreamAudioDestinationNode. Аудіограф запису не підключається до динаміків. Жіночий коментар накладено окремо, з автоматичним приглушенням ігрового звуку під мовлення. Озвучку/музику самої публічної гри не замінювали. Музика — чинний river-combat трек гри, не тема головного меню.

Вихідні файли збережені локально: `gameplay-source.webm`, `voice-0.wav` … `voice-4.wav`, `narration-track.wav`. Відео ще не опубліковане у соцмережах.

Відтворення процесу:
1. Запустити dev server на 127.0.0.1:5178 і `python3 tools/capture-receiver.py`.
2. Відкрити `/tools/capture-narrated.html` у Codex Browser і натиснути запис.
3. `python3 tools/generate-video-narration.py --env-file <private-env-file>` (готові кліпи повторно не генерує).
4. `python3 tools/mix-gameplay-narration.py docs/marketing/captures/narrated/gameplay-source.webm`.
5. Після експорту зупинити локальний receiver. Ніколи не додавати credentials у репозиторій.

Перевірки: обидва audio-тести пройшли, включно з ізоляцією виходу запису від динаміків; TypeScript пройшов; переглянуто контактний аркуш кадрів. Медіафайли перевіряються ffprobe/ffmpeg без звукового відтворення.
