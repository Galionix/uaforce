# Повний крок обох ніг · 2026-09-10

Власник повторно повідомив, що під час бігу головних персонажів рухається лише одна нога.

## Причина

Попередня правка перемикала індекси 1→0→2→0 й не блокувала їх стрільбою. Це не виправляло самі пози: у вихідних аркушах Шевченка, Лесі, Франка, Бандери та інших кадри 1/2 майже повторюють один контакт ніг. Тест на різні номери кадрів не доводив повний цикл кроку.

## Зміна

Для всіх 11 бійців і Мавки додано окремий восьмифазний цикл: контакт, опора, відштовхування, повернення ноги; друга нога йде зі зсувом у півциклу. Коліна й стопи рухаються незалежно. Текстури обох ніг беруться з різних ділянок наявного спрайта; персонажі не перемальовані й нові PNG не генерувалися. Обличчя, одяг і зброя збережені. Для довгого одягу верх ніг прихований під його краєм.

Кадри один раз збираються в пам’яті через Canvas на цілочисельній піксельній сітці; без плавних обертань та масштабування кожної фази за різними bounds. Опора й масштаб сталі, тіло має невеликий рух на кроці. Повна фігура дзеркалиться для бігу ліворуч, окремі черевики не дзеркаляться. Стрільба, перезарядка й застосування вмінь на землі не зупиняють ноги; стрибок, стіни й драбини мають пріоритет. Пауза зупиняє ігровий годинник анімації. Обидва гравці коопу використовують той самий рендер.

## Верифікація

`tools/verify-run.html?silent=1`: анімація та 8 статичних фаз для кожного з 12 образів. Фактичні Canvas-зображення мають 8 різних фаз; окремо перевірено перенесення обох стоп уперед/назад і чергування опори. `tools/verify-roster.html?silent=1`: біг зі стрільбою в обидва боки у справжньому View/World; помилок консолі немає. Тестові сторінки не входять до release.

Автоматичні сценарії перевіряють повний крок обох ніг, розділені текстури всього складу й пріоритет руху при атаці. Існуючі артефакти зображень і звуку не змінені. Усі перевірки без програвання звуку.

Повний набір: 286/286 тестів пройшли. `npm run build:release`: 106 файлів, 70.65 MiB; ZIP перевірено.
