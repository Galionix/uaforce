# Повна заміна SFX — локальний кандидат

Вказівка власника: перегенерувати весь набір ефектів в одному стилі без оплати сервісам. [Художні правила](SFX_STYLE.md). Музика, музичні рифи та схвалений іменний анаунсер залишаються окремими матеріалами.

## Джерело

Stable Audio 3 Small SFX, офіційний MLX на цьому Mac. Runtime `779434a908193105335fd8d833418603625b2859`; оптимізовані ваги `stabilityai/stable-audio-3-optimized`, revision `da6edc54ddba10bfd79a077102ded687f80e882b`. Без платного API чи орендованого GPU. Умови: [Stability AI Community](https://stability.ai/license).

У списку 389 цільових фрагментів: 349 старих банківських ефектів, чотири старі окремі SFX, 21 реакція піхоти, 12 мокрих ефектів, три фінали босів. Це кількість ігрових файлів, а не обіцянка 389 незалежних придатних майстрів: невдалі дублі відхиляються; чистий новий майстер може дати кілька варіантів монтажу.

## Контроль якості

Перший короткий FP16 тест відхилено через шумові артефакти. Контроль із FP32, шістьма секундами й простішими запитами дав розпізнавані звуки. Ці зміни перевірялися разом; окремий корінь проблеми не доведено. Складні мокрі фактури потребували іншого seed і CFG 3 із негативним запитом. Перші невдалі Lyria-майстри не використовуються як SFX.

Усі 389 змонтованих WAV перевірені локальним CLAP за фактичними PCM-даними. Семантичний пошук допоміг вибрати інтервали з потрібними матеріалами; композиційні шари вирівняні перед змішуванням. Це відсіювання явних невідповідностей, **не художнє схвалення і не людське прослуховування**. Зокрема тембри щипкових струн і стилізованих двигунів потребують оцінки на слух.

Попередні відповіді Gemini щодо аудіо були непослідовними; `LOCAL_SFX_REVIEW.json` зберігає їх лише як попередні записи зі статусом `needs-local-confirmation`. Вони не підтверджують якість готового банку. Хеші та фактичний фінальний CLAP-скринінг зафіксовані в `LOCAL_SFX_SCREENING.json`.

Майстри збережені в ігнорованому `tools/audio-source/local-sfx`; кожен має prompt, seed, модель, версію runtime й хеш. Монтаж у `LOCAL_SFX_EDITS.json` також прив'язаний до хешів майстрів. `LOCAL_SFX_BASELINE.json` зберігає старий перелік і часові обмеження, щоб нова генерація не залежала від уже заміненого банку.

## Відтворення

1. Зібрати каталог: `python3 tools/local-sfx-catalog.py`.
2. Генерувати/продовжити: `python3 tools/generate-local-sfx.py` (можна `--ids`). Використовує локальне ізольоване MLX-середовище.
3. Додаткові матеріали: генератор із `--catalog docs/LOCAL_SFX_PRIMITIVES.json`; `tools/select-local-sfx-windows.py` вибирає інтервали через ізольоване CLAP-середовище. `tools/curate-local-sfx.py` зберігає монтаж і композиції.
4. Змонтувати кандидатів: `tools/audio-source/stable-audio-3/optimized/mlx/.venv/bin/python tools/pack-local-sfx.py`.
5. Перевірити PCM: `tools/audio-source/sfx-audit-env/bin/python tools/check-local-sfx-content.py`.
6. `tools/pack-local-sfx.py --install-candidate` встановлює лише повний набір із відповідними хешами скринінгу, позначаючи `humanAudition: false`. `--install` окремо вимагає прийняті хеш-прив’язані рецензії на кожен фрагмент.
7. `npm test` та `npm run build:release`.

Жоден крок не програє звук. Не використовувати `--play`. Старий `build-combat-sfx.py` заблокований від випадкового повернення бібліотечних ефектів.

## Інтеграція

Роль і причина загибелі передаються подією світу, включно з co-op. Варіанти реакцій не повторюються одразу. Падіння фрагментів звучить лише на першому реальному ударі об підлогу, з обмеженням частоти. Боси мають окремий звук руйнування поряд зі схваленим оголошенням.

Двигуни прив'язані до живої техніки як цикли; повторні події не накладають довгі записи. Слоти циклів стабільні при заміні JS-об'єктів мережевим snapshot. Пауза, загибель/видалення об'єкта та вихід із техніки завершують відповідний цикл.

## Результат перевірки

- Встановлено 389/389 ефектів, усі 349 попередні фрагменти мають інші SHA-256. Чотири окремі legacy SFX більше не завантажуються й не потрапляють у release.
- Банк: mono PCM16, 24 kHz, 201.52575 с; SHA-256 `e56bb2630691392311e4ceed7beb6fb5a4b04ed03dc05ccb7e669b7982c9a9a4`.
- 277 тестів пройшли; release build успішний: 106 файлів, 70.43 MiB.
- Локально перевірено головне меню, старт одиночної гри, окреме меню паузи та сторінку порівняння. Помилок у консолі не виявлено. Усі перевірки без звуку, `?silent=1`.
- Порівняння нового й попереднього наборів: `/tools/review-sfx.html` на dev-сервері. Програвання лише після ручного натискання; у `?silent=1` кнопки вимкнені. Сторінка не входить до публічного release.

**Статус: `local-playtest-candidate`, встановлено локально; людське прослуховування ще не проведено. Cloudflare не оновлено цією поставкою.**
